# Contributing

Bug reports, documentation corrections, and design discussions are welcome through GitHub Issues.

The project is not currently accepting code contributions. The public source licence permits unmodified personal evaluation but does not grant permission to create derivative works. This keeps authorship and portfolio provenance unambiguous.

For a useful issue, include:

- the script and command used;
- the Windows and PowerShell versions;
- the expected and actual result;
- sanitized error text; and
- whether the lab differs from the documented topology.

Never attach credentials, event logs containing personal data, VM images, registry exports with secrets, or screenshots showing a Windows LAPS password.
